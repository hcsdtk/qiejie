# 切界

一个纯浏览器运行的画线图片分割工具。上传或粘贴图片，从画布一侧拖到另一侧画出分割线，即可导出带透明背景的独立 PNG 切片，或一次下载 ZIP。

## 功能

- 拖拽、文件选择与剪贴板粘贴上传
- 直线分割，水平/垂直/45° 辅助校正，端点自动吸附图片边缘和已有线条
- 视图自动适应窗口，支持 5%–400% 缩放、100% 还原及滚动查看长图
- 撤销、清空、切片预览与单张下载
- 一键把多个 PNG 保存到文件夹，也可使用 `fflate` 在浏览器本地打包 ZIP
- 图片数据不离开本机浏览器

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

核心界面与分割算法位于 `app/page.tsx`，站点使用 vinext 构建。
