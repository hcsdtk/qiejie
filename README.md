# 切界

一个纯浏览器运行的画线图片分割工具。上传或粘贴图片，从画布一侧拖到另一侧画出分割线，即可导出带透明背景的独立 PNG 切片，或一次下载 ZIP。

## 功能

- 拖拽、文件选择与剪贴板粘贴上传
- 直线分割默认启用角度校正与端点吸附；按住 Shift 强制锁定 0°/45°/90°
- 画线时显示起点与落点双放大镜，便于确认精确落点
- 可在画布工具栏开启背景参考网格，不覆盖图片且不会出现在导出图片中
- 分割线可选中、拖动端点、单独删除，支持完整撤销与重做
- 裁剪、顺时针旋转、水平/垂直翻转
- 2×2、3×3、三栏或最多 12×12 的自定义等分网格
- 视图支持整体适应、宽度铺满、高度铺满、5%–400% 缩放、100% 还原及滚动查看长图
- 大图使用轻量预览，切片仍按原图像素输出
- PNG、JPG、WebP 格式与 50%/100%/200% 尺寸、JPG/WebP 质量设置
- 切片预览与单张下载，一键保存到文件夹，也可使用 `fflate` 在浏览器本地打包 ZIP
- 图片数据不离开本机浏览器

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

核心界面与分割算法位于 `app/page.tsx`，站点使用 vinext 构建。
